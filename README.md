# Electron Configuration Lab: Build, Arrange, and Discover Electrons

An interactive lab for 10th-grade New York State Regents Chemistry (NYSSLS HS-PS1-1). Students build electron arrangements, count valence electrons, find periodic patterns, and work up to subshell configurations and orbital diagrams.

**Time:** 45–60 minutes · **Format:** one self-contained `index.html`, no install or sign-in.

## Modules

1. **How many electrons?** Click any element (1–36), predict the electron count of the neutral atom, and reveal the atom. Includes a discovery question and 5 random checks.
2. **Build energy levels:** drag grey electrons onto n = 1–4, with live counters and a 2-8-1 style readout. Guided lithium, sodium, and calcium, plus any of the first 20 elements. Includes a capacity check (2, 8, 18, 32).
3. **Write configurations:** enter the atomic number, electron count, each shell, and the configuration. Each part is checked separately, with three hints and an explanation.
4. **Valence electrons:** the outer shell is outlined in gold and students click its electrons to count them. Also: Period 2 table, Group 1 comparison, and a 2-8-6 challenge.
5. **Subshells and orbitals:** a step-by-step Aufbau animation (elements 1–36) and an orbital-diagram builder. The builder checks the Aufbau principle, Hund's rule, and the Pauli exclusion principle. Includes a sulfur challenge and the chromium and copper exceptions.
6. **Configuration Detective:** 15 cases (5 fixed, 10 random). Students find electrons, Z, element, symbol, valence, and group. Formats get harder (shell diagram, then subshell notation) as students build a streak.
7. **Ions (extension):** make Na⁺, Cl⁻, Mg²⁺, O²⁻, and Al³⁺ and watch the configuration change.

**Final assessment:** 20 questions (4 electron counts, 5 shell configurations, 4 valence, 3 periodic patterns, 2 identify elements, 2 subshell/orbital diagram). Some questions use shell diagrams. Includes a skill mastery report, retry of incorrect questions, unlimited new practice sets, and a summary students can copy or print.

## Notes for teachers

- Particle colors are fixed: protons red, neutrons blue, electrons grey. Shells are highlighted with outlines, never by recoloring electrons.
- Shell configurations follow the NYS Reference Table (for example, K = 2-8-8-1, Sc = 2-8-9-2).
- Targeted feedback addresses the eight listed misconceptions. Examples: "all shells hold 8", 2-8-9 for potassium, valence = total, and "configuration = total electrons".
- Four proficiency levels adjust hints and supports. Includes read-aloud, a glossary, sentence starters, reduced motion, keyboard and touch support.
- Progress is saved only in each student's own browser.

To use it, open `index.html`, or enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → main / root).
